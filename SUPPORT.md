# Support

Booking Kiosk is a demo project maintained on a best-effort basis; there is no service level.

- **Questions and ideas:** open an issue with the feature request template, or start a discussion if discussions are enabled.
- **Bugs:** use the bug report template, with steps to reproduce against the seeded demo data.
- **Security problems:** never in public; see [SECURITY.md](SECURITY.md).

Supported: the latest release on `main`, run as described in the [README](README.md) (Docker Compose or `make setup`). Not supported: production deployments, databases other than PostgreSQL 14 or later, and modified forks.

Start with the [documentation map](docs/README.md); the [tutorial](docs/tutorials/getting-started.md) walks through a first booking.
